# Responsive Portfolio Page

Адаптивная одностраничная портфолио-страница с современным дизайном. Проект демонстрирует использование CSS Grid и Flexbox для создания отзывчивого интерфейса.

## Описание

Простое и функциональное портфолио, построенное на HTML5 и CSS3. Включает навигационное меню, секцию "О себе", сетку навыков с карточками и футер. Проект использует современные CSS технологии для создания адаптивного макета.

## ✨ Особенности

- Полностью адаптивный дизайн
- Навигационное меню с плавной прокруткой
- Секция "О себе" с информацией
- Интерактивная сетка навыков с hover-эффектами
- Использование CSS Grid с auto-fit и minmax()
- Мобильная навигация
- Чистый и современный код

## 🚀 Быстрый старт

1. Откройте файл `index.html` в вашем браузере
2. Или используйте локальный веб-сервер:

## 🛠 Использование

### Настройка контента

Откройте `index.html` и измените:

- **Логотип/Имя**: Измените "SNinja" на ваше имя (строка 12)
- **Навигация**: Обновите ссылки в меню (строки 15-18)
- **О себе**: Измените текст в секции "About Me" (строка 26)
- **Навыки**: Добавьте или удалите карточки навыков (строки 33-40)

### Настройка стилей

В файле `style.css` можно изменить:

- Цветовую схему (строки 8, 46, 79, 100)
- Размеры шрифтов
- Отступы и размеры карточек
- Breakpoints для адаптивности (строки 111, 132)

## 🧪 Технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Стилизация
  - Flexbox для навигации и header
  - CSS Grid для сетки навыков
  - Media Queries для адаптивности

## 📱 Адаптивность

Проект оптимизирован для трех размеров экранов:

- **Десктоп**: Полная версия с горизонтальной навигацией
- **Планшет** (до 768px): Вертикальная навигация, 2 колонки в сетке
- **Мобильный** (до 400px): Вертикальная навигация, 1 колонка в сетке

## 🎨 Особенности дизайна

- Серый цветовой фон для header и footer
- Светло-серый фон для контентных секций
- Темно-серый фон для сетки навыков
- Hover-эффекты с трансформацией и тенью на карточках
- Скругленные углы (border-radius: 8px)
